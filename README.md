
# 📊 Interactive Dynamic Sales Report Dashboard

## 📌 Project Overview

The **Interactive Dynamic Sales Report Dashboard** is an Excel-based data visualization and business intelligence project designed to analyze sales performance through interactive charts, KPIs, filters, and category-wise analysis.

The dashboard provides a quick overview of important business metrics such as **Sales, Orders, Quantity, Profit, Quarterly Sales, Category Sales, and Quantity by Category**.

It allows users to interact with the dashboard using filters such as **Region** and **Category**, making it easier to analyze sales performance from different perspectives.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales performance.
- Track total orders and quantity sold.
- Monitor profit generated from sales.
- Compare quarterly sales performance.
- Analyze sales across different categories.
- Understand category-wise quantity distribution.
- Provide interactive filtering by region and category.
- Present complex sales data in an easy-to-understand visual format.

The dashboard provides a category-wise sales visualization to understand the contribution of different product categories.

- Art
- Computer
- Electronics
- Mobiles
- Storage

### 7. 📦 Quantity Sales

A treemap visualization represents the quantity sold by different product categories.

The dashboard includes filters/slicers for:

**Region**
- East
- North
- South
- West

**Category**
- Art
- Computer
- Electronics
- Mobiles
- Storage

These filters allow users to dynamically analyze specific regions and categories.
